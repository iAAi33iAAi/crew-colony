# crew-colony

**Multi-agent colony concept and repository scaffold**

## Current repository state

The current live repository contains src/__init__.py, tests/__init__.py, README.md, and LICENSE.

The executable crew_colony.py runtime described by older README text is not currently present, and the repository does not contain the previously claimed 7-agent implementation or 21-test suite.

## Concept

The project describes a future multi-agent orchestration model built around human sovereignty, non-extraction, lineage/auditability, deterministic planning, and a CODE-TREE / FREE-THREE / MIRROR conceptual architecture.

The 24-cell / icositetrachoron geometry is a governance metaphor and design framework here. It is not evidence of an implemented geometric runtime.

## Historical design values

MANNA is described by project material as:

- Human: 84%
- Vault: 15%
- Architect: 1%

Conservation Law 0 is described as approximately 1.008.

These are project-design values, not independently validated economic or scientific constants.
